# 🍷 Vino Wine Store App

**Vino Wine Store App** is a production-ready Flutter App with a Firebase backend — designed for wine shops, bottle stores, vineyards, and wine brands. It provides a modern online wine-shopping experience with product discovery, secure checkout, order tracking, and built-in customer rewards.

### Core Features:

* **Email/password authentication** with sign up, login, and password reset
* **Searchable home screen** with a live wine catalog, categories, and cart badge
* **Wine categories** such as Red, White, Rosé, Sparkling, and Champagne
* **Wine detail screen** with product information, bottle size, pricing, and quantity selector
* **Add-to-cart functionality** with real-time cart updates
* **Smart cart management** with item editing, quantity controls, and price summary
* **Secure checkout** with saved or new card payment options
* **Delivery address management** for convenient wine ordering
* **Order confirmation and tracking** with order status updates
* **Order history** with complete itemized order breakdowns
* **Wishlist/favorites** for saving wines for later
* **Wine loyalty rewards** where customers earn points from purchases
* **Redeem rewards** using accumulated loyalty points
* **Promotional offers and discounts** for selected wines and collections
* **Customer profile** for managing personal information, addresses, and preferences
* **Real-time Firebase database** for products, users, carts, orders, payments, and rewards

## Getting Started

This project is a Flutter application built with FlutterFlow. 

### Prerequisites
* [Flutter SDK](https://flutter.dev/docs/get-started/install) (stable channel)
* Firebase account and project configured with Firestore and Authentication

### Running the App
1. Clone the repository and navigate to the project directory.
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app on your connected device or emulator:
   ```bash
   flutter run
   ```
